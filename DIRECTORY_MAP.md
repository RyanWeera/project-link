# Directory Map: project-link
Start here: `hooks/`

## Folders
- `.claude-plugin/` - plugin manifest and the marketplace file that makes this repo installable
- `hooks/` - the mod's code and its tests
- `types/` - the `$.state` contract and the mailbox message types

## Where to change things
- Mailbox, project discovery, cold-chat rule -> `hooks/`
- Tools, `/inbox`, `/autolink`, the bar above the prompt -> `hooks/`
- `/messages`, `/edit`, the Edit messages pane -> `hooks/`
- Stored values or message shapes -> `types/`

## Ignore when searching
- `.git/` - git data
- `.claude-plugin/types/` - generated by the engine
- `graft/` - local graph cache, git-ignored
